# 《牛来》3D 跑酷游戏 · 视觉设计参考文档

> 本文档基于《牛来》电影公开资料（百度百科、影评、媒体报道）调研整理，作为游戏
> "牛来·梦境奔跑（Niulai: Dream Runner）"的视觉设计规范依据。

## 一、电影背景速览

| 项 | 内容 |
|----|------|
| 片名 | 《牛来》（2026） |
| 导演 / 编剧 | 信雨萌 / 孙丽芳（母子二人，耗时 5 年独立完成） |
| 片长 / 类型 | 86 分钟 / 水墨写意动画 |
| 官方美术定位 | "纯水墨写意美术风格，水墨晕染出的东方意境画面具有美学观赏价值" |
| 叙事结构 | 虚实交织的梦境叙事：现实（草原开篇/结尾）+ 梦境（成长历练主体） |

**剧情梗概**：草原上初生的孱弱牛犊"牛来"迟迟无法站立，母牛为它取名"牛来"，盼它迎难
而上。一只从荒漠长途飞来、筋疲力尽的云雀落在小牛身边，牛来带它坠入漫长梦境。梦中，
云雀以旁观者视角见证牛来的成长：与豹子"豹拉"的跨物种友谊、狼群袭击中牛妈妈舍身护
子、独自直面恐惧，最终觉醒为守护草原的勇士。惊醒后一切是梦，而牛来终于稳稳站立。

## 二、核心角色设定

### 1. 牛来（玩家角色）
- **形象**：初生小牛犊，体型圆润小巧，天生孱弱、眼神懵懂
- **游戏转译**：乳白色（`#f7f4ec`）圆润身体 + 大头大眼 + 淡赭色小牛角 + 黑色小蹄，
  体现幼崽的稚拙感与"向阳而生"的纯净气质

### 2. 云雀（收集品意象）
- **形象**：从荒漠飞来的小鸟，梦境的见证者，与牛"遥遥相望"（官方海报构图）
- **游戏转译**：金色羽毛（`#d4a94e`）作为收集品；远景 V 形飞鸟剪影作氛围元素

### 3. 豹拉（豹子，跨物种挚友）
- **形象**：年轻的豹子，故作柔弱求助，与牛来成为朋友却遭牛群偏见
- **游戏转译**：本作暂不做可交互角色，保留在文档中供后续扩展

### 4. 狼群（障碍意象）
- **形象**：成群结队袭扰牛群，狩猎阴影笼罩草原，是全片最大生存威胁
- **游戏转译**："墨狼"作为高大障碍（需变道躲避），灰墨色（`#5a5f5c`）狼形剪影

### 5. 牛妈妈
- **形象**：慈爱坚韧，危机中挺身而出牺牲自己
- **游戏转译**：暂不做可交互角色，保留扩展空间

## 三、场景与标志性元素

| 元素 | 电影语境 | 游戏转译 |
|------|----------|----------|
| 草原 | 故事主舞台，牛群栖息地 | 三车道淡彩草原跑道（淡青绿 `#9db98a`） |
| 荒漠 | 云雀飞来之地，干涸苍茫 | 暂不实现独立场景，以色调渐变暗示 |
| 梦境 | 虚实交织、水墨晕染 | 随奔跑进度雾色渐变（入梦感），青墨色调 lerp |
| 云雾山水 | 官方海报：云雾缭绕、留白构图 | 多层水墨远山剪影 + 淡墨雾（THREE.Fog） |
| 草蛇 | 牛来童年被咬，见树枝草绳发抖 | 地面蛇形障碍（跳跃躲避） |
| 迁徙 | 牛群长途跋涉逃亡 | 无尽奔跑的叙事底色 |
| 汽车"巨兽" | 象征人类威胁 | 暂不实现，保留扩展空间 |

## 四、色彩方案（水墨体系）

### 基础色板
| 用途 | 色值 | 说明 |
|------|------|------|
| 宣纸底色（天空/雾） | `#f5f0e6` | 米白宣纸，画面基底 |
| 天空上部 | `#ede7d8` | 略深宣纸色，营造苍穹 |
| 天空地平线 | `#f7f2e4` | 暖白晕染 |
| 淡彩草原 | `#9db98a` | 淡青绿，水墨淡彩 |
| 车道色带 | `#c2cfa4` | 略亮的黄绿，区分跑道 |
| 乳白小牛 | `#f7f4ec` | 主角色 |
| 金羽 | `#d4a94e` | 唯一暖色点缀，视觉焦点 |
| 墨岩 | `#6f7570` | 中墨灰 |
| 枯木 | `#8a6f52` | 赭棕 |
| 草蛇 | `#5c7a52` | 墨绿 |
| 墨狼 | `#5a5f5c` | 灰墨 |
| 牛角 / 鼻吻 | `#d9c9a8` / `#e8b8b0` | 淡赭 / 浅粉 |

### 墨分五色（远山层次，由近及远）
`#3a3f3d`（浓）→ `#6b726c`（重）→ `#a8ada6`（淡）→ `#d3d6cf`（极淡）
配合雾效形成"墨晕"层次，最远层近乎融入宣纸底色。

### 入梦渐变（氛围随进度）
- 起始：宣纸暖白雾 `#f5f0e6`
- 深入：向青墨 `#c9d2cc` 轻微 lerp，雾略加密
- 呼应电影"虚实交织的梦境叙事"

## 五、渲染风格约定

1. **材质**：`MeshToonMaterial`（阶梯光影）为主，扁平色块 + 柔和环境光，贴近水墨平涂
2. **雾**：`THREE.Fog` 宣纸色，远山与障碍远景自然晕染
3. **天空**：渐变穹顶（宣纸色系），无贴图，纯色晕染
4. **光照**：HemisphereLight（天光宣纸色 / 地光草色）+ 柔和 DirectionalLight，无阴影贴图
5. **构图**：低饱和、大量留白、地平线压低，远景为主、近景点缀
